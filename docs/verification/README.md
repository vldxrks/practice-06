# Результати перевірки

- SDK: Flutter 3.35.7, Dart 3.9.2.
- `analyze.txt`, `stage-1-analyze.txt`: обидві версії без зауважень.
- `tests.txt`: 10 успішних тестів; окремий тест захоплення доказів пропущено за замовчуванням.
- `evidence.txt`: тест захоплення доказів виконано окремо, успішно.
- `stage-1-tests.txt`: успішний сценарій першого етапу.
- `web-build.txt`, `stage-1-web-build.txt`: Web-збірки завершилися успішно.

Результати отримано справжніми інструментами Flutter. Для роботи SDK
у контейнері без procfs використано локальну обгортку сумісності процесу;
джерела застосунку, перевірки та правила аналізатора не змінювались нею.
Обгортка не входить у проєкт і не потрібна у звичайному Flutter-середовищі.

Скриншоти в `../screenshots/` створено з Flutter render tree,
час у даних зафіксовано для повторюваності. Android SDK у середовищі
не налаштовано, тому Android APK не збирався.

Повідомлення Web-компілятора про необов'язковий шрифт CupertinoIcons
не є помилкою аналізатора чи збірки: застосунок використовує Material Icons
з Flutter SDK. Сторонній пакет cupertino_icons не додано згідно з вимогою
використовувати лише SDK.
