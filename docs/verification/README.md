# Походження доказів перевірки

Перевірки виконано на Flutter 3.35.7 / Dart 3.9.2 у Linux-середовищі підготовки проєкту. Логи команд збережено без підміни результатів. Абсолютні шляхи в них належать тимчасовому робочому каталогу.

- `rebuild-before.txt`, `rebuilds-before.json` та `tests-baseline.txt` отримані на базовій версії до оптимізації.
- `rebuild-after.txt`, `rebuilds-after.json` — на версії з `select`/`Selector`; фінальна перевірка також містить точні assertions лічильників.
- `tests.txt` — 10 звичайних тестів; спеціальний screenshot-тест запускається окремо.
- `evidence.txt` — успішний окремий запуск screenshot-тесту; PNG містяться в `../screenshots/`.
- `analyze.txt` і `web-build.txt` — фактичний аналіз і release-збірка для Web.

Середовище підготовки має обмежений `/proc` та нестандартні обмеження стека. Для запуску офіційних виконуваних файлів Dart/Flutter використано локальний launcher із більшим стеком і сумісним отриманням необов’язкової RSS-телеметрії через `getrusage`, коли `/proc/self/statm` недоступний. Правила аналізатора, код застосунку, assertions і результати тестів не змінювалися через ці обмеження. Цей launcher не потрібен у звичайному Flutter SDK і не включений до проєкту.

Web-компілятор повідомляє про відсутній необов’язковий шрифт CupertinoIcons; застосунок використовує Material Icons, збірка завершується успішно. Перевірки встановлення/запуску APK на Android та вимірювання FPS на фізичному пристрої не проводилися.

Віддалений CI відтворює перевірки стандартним Flutter SDK. Його фактичний статус слід дивитися на вкладці Actions; локальні логи не є підтвердженням віддаленого запуску.
